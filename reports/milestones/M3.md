# M3 conservative predecoder checkpoint

Added predecoder.py and tests/test_predecoder.py. Selects isolated, mutually
unique active pairs on whole two-detector DEM error mechanisms. Parallel edges
with conflicting logical masks, decomposed correlated mechanisms and hyperedges
are excluded. Boundary corrections fall back to MWPM. This is a heuristic;
unique adjacency is not proof that the inferred physical error happened.
Uses original syndrome for disjoint selection, XOR residual support and logical
frame, then XORs the downstream MWPM observable prediction. No geometric guesses.
The rule is unweighted; downstream matching retains DEM probabilities/weights.
