# M1 — verified baseline

Added baseline.py, tests/test_baseline.py and demo/sweep CLI routing. Stim generates
rotated X/Z memory circuits; PyMatching uses the decomposed DEM. Observable flips
are scored per complete memory experiment, not per round. All four noise channels
are set to p in demo/sweep. No correlation-aware decoding is enabled.

Commands (project virtual-environment Python):
```
python -m pytest --basetemp=results/m1-tests-3 -q
python -m qec_project demo --crosscheck
python -m qec_project sweep --crosscheck
```
Set TMP and TEMP to the absolute results directory in this restricted environment
because Sinter uses temporary files. Initial tests failed on temporary-file access;
the local temporary directory resolved this. An initial sweep exposed floating-point
roundoff at the zero-failure Wilson lower endpoint; fixed and regression tested.
Final: 22 tests passed, including noiseless X/Z and exact same-sample Sinter adapter
agreement. This cross-check uses the same MWPM backend, not an independent algorithm
or independent Monte Carlo replication.

Demo: 21/1000 failures, P_L=.021, 95% Wilson interval [.0137757,.0318903].
Sweep: 18 points, X/Z, d=3/5/7, rounds=d, p=.001/.003/.005, 1000 shots each.
Saved CSV, manifest and real plot in reports/evidence/M1. Full circuits, DEMs,
configs and replay samples are under results/f2efb42957014d81b49d07cfb8c63411.
Zero observed failures imply an upper bound (~.003827 here), not perfect correction.
These are pipeline validation runs, not a threshold study or adequately powered
rare-event study. Seed 42 is repeated per point; cross-point independence is not assumed.
